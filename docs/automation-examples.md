# Automation examples

## Talking-head TikTok

`Media → Transcribe → Remove fillers / Remove silence → Captions → Highlights → TikTok style → Shorts → Export`

## Multi-platform short video

`Media → Transcribe → Highlights → Auto B-roll → Approval → TikTok / Instagram / Facebook / YouTube branches → Export`

## Event recap

`Folder input → Merge clips → Stabilize / Color / Audio → Highlights → YouTube 16:9 → Export`

## Mobile-assisted production

1. Open a project on the desktop.
2. Start Mobile Control.
3. Upload an MP4 from the phone.
4. Run a saved workflow.
5. Approve proposed visuals.
6. Monitor and control jobs from the phone.
